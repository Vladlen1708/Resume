### [Credit Score — оценка надёжности заёмщиков](https://github.com/Vladlen1708/Credit-score-first-pet-project-)
Мультиклассовая классификация кредитных рисков на датасете в 100 тыс. записей. Метрика выбрана из постановки задачи: цена ошибки — выданный кредит ненадёжному клиенту, поэтому оптимизировал recall на классе Poor, сознательно жертвуя precision на Standard.
Очистка артефактов в числовых полях, корреляционный анализ, работа с дисбалансом классов через веса. Проверил гипотезу о логарифмировании скошенных признаков, обучив две модели на одних и тех же гиперпараметрах — вариант с логарифмированием оказался лучше на миноритарных классах.
**Результат:** recall 0.87 на целевом классе, ROC-AUC 0.93.
`CatBoost` `scikit-learn` `pandas` `seaborn`
